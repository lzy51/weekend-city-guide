# 🧭 周末城市探索指南 · Weekender

> 大学生周末去哪玩？—— 一个把「种草 → 组队 → 出发 → 打卡 → 分享」做成闭环的 H5 小应用。
> 核心亮点：**外卖拼单式的「组队出发」体验**。

## 💡 解决什么问题

| 痛点 | 方案 |
|---|---|
| 信息分散、攻略过期、滤镜太重 | 结构化活动库 + 用户时效性反馈（还在/已结束） |
| 预算、天气、同伴时间难同时满足 | 条件式推荐：按预算/时长/人数/偏好生成方案，**算总成本** + 自带**雨天 Plan B** |
| “有人一起去吗”无人响应 | **拼单式组队**：发起 → 微信邀请卡 → 好友一键加入 → 实时进度 → 人满自动成团撒花 |
| 去过就忘、攻略懒得写 | 到场打卡 → 点亮城市地图/解锁徽章 → 打卡数据**自动生成攻略卡** |

## ✨ 五大模块

1. **🏠 推荐首页** —— 10 秒三问（预算/时长/同行/偏好）→ 生成 Top3 方案，人均总花费透明（🎫+🚇+🍜），周日下雨自动标注 Plan B
2. **🔍 活动库** —— 展览/市集/演出/徒步/户外分类筛选，按总花费/剩余天数排序，学生票价格高亮
3. **🧭 行程（核心）** —— 拼单式组队：定集合时间地点人数 → 邀请卡片/复制链接 → 好友落地页一键加入 → 头像进度条实时更新 → 倒计时截止 → 人满**成团撒花** + 集合信息卡
4. **🏅 我的** —— 打卡记录、点亮 6 大城区、7 枚探索徽章
5. **📤 攻略生成器** —— 由打卡真实数据（花费/评分/照片/路线）一键生成可分享的攻略卡

## 🚀 快速开始

```bash
# 本地：直接双击 index.html 即可（零依赖、无需构建）
open index.html
```

## 🎬 3 步体验「拼单式组队」

1. 活动详情页点 **「发起组队」**，选集合时间/地点/人数 → 生成局
2. 点 **「邀请好友」→ 复制链接**，**再开一个浏览器窗口**粘贴打开（= 一位新好友）→ 点 **「我要加入」**，两边进度实时同步
3. 人凑齐 → 自动**成团撒花** → 「到场打卡」点亮城区 → 「我的」页生成攻略卡

> 💡 单窗口也可以：组队页有「🤖 模拟一位好友加入」按钮。

## 🛠 技术说明

- 纯原生 HTML/CSS/JS 单页应用，无框架无依赖
- `localStorage` 持久化 + `storage` 事件实现**跨标签页实时同步**（模拟多端加入）
- 邀请链接用 `#join=<队伍ID>` 落地，适配 GitHub Pages 子路径部署
- Canvas 手写撒花动画；移动端 H5 风格（桌面居中手机壳预览）
